## The line

> My agent keeps a lessons file so it never repeats a mistake — it just makes new ones.

One sentence, 85 characters. My own agent really does keep a lessons file after every mistake — and still finds brand-new ways to fail. The joke lands on the futility loop: the file exists to stop repeats, so the agent simply innovates.

## How it works

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```
